# Contoh Storyboard — Mode B (Bongkar Benda)

Topik: **Rice Cooker Kok Bisa Tahu Nasinya Sudah Matang?**
Naskah contoh ada di `naskah-contoh.txt` (55 kata, ±30 detik).
Rekam naskah itu menjadi MP3 (TTS apa pun), upload MP3 + file musik
pilihanmu ke root repo, lalu mulai sesi Claude Code dengan prompt
dari skill (Mode: B, topik ini, sumber fakta: catatan di bawah).

## Alur fase (mengikuti struktur Mode B di references/mode-b.md)

1. **Konteks** — diorama dapur isometrik; rice cooker utuh di atas
   meja. Hook = kalimat pertama narasi.
2. **Zoom + label** — kamera masuk; label "RICE COOKER — penanak
   nasi listrik". Kalimat undangan: "Coba kita lihat dalamnya."
3. **DIBONGKAR** — tampak ledakan: penutup, panci dalam, elemen
   pemanas, sensor tengah, tuas saklar — label dwibahasa muncul
   mengikuti narasi.
4. **DIBELAH** — belahan panci berisi nasi + air; gelembung
   mendidih; readout suhu menanjak lalu tertahan di 100°C; indikator
   "MASAK" menyala.
5. **Makro mekanisme** — sensor magnet di dasar: suhu merayap
   101→103°C, magnet melemah melewati titik Curie, tuas lepas —
   teks peristiwa "klik!", indikator beralih ke "HANGAT".
6. **Payoff** — kamera menarik mundur; label prinsip: "SUHU
   MENAHAN DIRI — selama ada air, api sebesar apa pun tertahan di
   100°C." Fade ke hitam.

## Catatan fakta (sumber untuk sesi)

- Selama masih ada air bebas, suhu dasar panci tertahan di titik
  didih air (±100°C) karena energi panas dipakai untuk penguapan.
- Setelah air terserap nasi, suhu dasar naik melewati 100°C.
- Sensor memakai magnet ferit yang kehilangan daya tariknya di atas
  titik Curie (±103°C); tuas terlepas dan saklar berpindah dari
  MASAK ke HANGAT. Mekanisme klasik rice cooker elektrik.
